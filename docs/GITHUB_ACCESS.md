# GitHub access checklist

If Grok gets **404** on `jessyincognitoarcher-lab/Medical-Chat`:

1. Confirm the repo exists under that exact owner and name.
2. Open GitHub → Settings → Applications → **Authorized OAuth Apps** or **GitHub Apps**.
3. Open the app used by Grok / xAI.
4. Grant access to **Medical-Chat** (or “All repositories”).
5. Alternatively: temporary **Public**, push files, then set **Private** again.
6. Send the repo URL again after changing permissions.
